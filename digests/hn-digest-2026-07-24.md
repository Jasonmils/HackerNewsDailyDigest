## 10. [Show HN: OneCLI – OSS credential gateway that keeps secrets out of AI agents](https://github.com/onecli/onecli)
*Show HN: OneCLI – 让 AI 代理远离密钥的开源凭证网关*
▲ 82 分 · Jonathanfishner · [29 评论](https://news.ycombinator.com/item?id=49023427)

📝 **概要**：OneCLI 是一个开源凭证网关，AI 代理使用伪造 API key 发起请求，由 Rust 编写的中间人代理动态注入真实凭证，避免密钥泄露或被提示注入攻击。支持 AES-256-GCM 加密存储、Bitwarden 集成和人类审批控制。

🧭 **联系你的知识背景**：中间人（MITM）通常是一种攻击手段，OneCLI 则将其变为安全功能：所有代理请求必经代理，由网关替换凭据，如同在模型推理前加入一个强制认证层。

**🔑 要点**
- **Rust 网关** 以中间人方式拦截 HTTP 请求，将占位符密钥动态替换为真实 API key，代理全程不可见。
- 支持 **AES-256-GCM 加密** 存储及 **Bitwarden/1Password** 集成，可实时拉取外部凭证而不持久化到服务器。
- 提供 **human-in-the-loop 审批**，敏感操作由网关在网络层强制拦截并等待人工确认，防止被操控的代理滥用。
- 一行安装 `curl -fsSL https://onecli.sh/install | sh`，兼容 Claude Code、Cursor、Codex 等主流代理框架。

💬 **讨论**：评论认可代理-凭证分离的经典模式，但对 OneCLI 与 agent-vault、clawpatrol 的差异存疑，并调侃中间人拦截成了新功能。

🏷️ `AI 代理安全` · `凭证管理` · `中间人代理`
