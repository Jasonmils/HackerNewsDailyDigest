DeepMind's WeatherNext model achieves breakthrough forecasting cyclones

DeepMind 的 WeatherNext 模型在气旋预测上取得突破

▲ 393 分 · bhavansig · 118 评论

WeatherNext 将热带气旋的路径、强度和风结构预测提升了一个整天的提前量，三天的预报已相当于此前两天的精度，相当于十年的气象学进步；已在 2025 飓风季帮助 NHC 成功预测飓风 Melissa，且已开源 WeatherNext 2 和 WeatherNext Cyclones 模型。

🧭 联系你的知识背景 传统天气预报依靠物理方程的数值模式（NWP）在超算上运行，而 AI 模型直接从历史数据学习，推理仅需秒级；WeatherNext 用深度学习在气旋预测上首次实现了‘额外一天预警’的跨越，推理效率远超 NWP。

  • 额外一天预警：3 天预报精度达到此前 2 天的水平，相当于十年气象进步，已发 Nature。
  • 实际验证于飓风 Melissa：2025 年帮助 NHC 提前预测快速增强和登陆牙买加，争取了关键备战时间。
  • 单模型集合预报：用 Functional Generative Networks 在 TPU 上不到一分钟生成 1000 个成员的 15 天预报，捕获极端尾部风险。
  • 开源 WeatherNext 2 与 Cyclones 模型：含 mini 版可运行于免费 Colab，供研究者和气象机构自由构建。

💬 讨论 评论普遍认可这是 AI 在真实世界产生影响的用例，比又一编程助手更有价值，并讨论 AI 预报模型相对传统 NWP 在效率和精度上的巨大优势。

Message your other Claude Code sessions

向其他 Claude Code 会话发送消息

▲ 70 分 · mfiguiere · 33 评论

Claude Code v2.1.224 起在 macOS 和 Linux 上原生支持跨会话消息，无需手动启用。Claude 可自行发现其他会话并传递发现、状态或决策，减少开发者在多个终端间复制粘贴上下文的重复劳动，并设置了严格的权限边界以防滥用。

🧭 联系你的知识背景 Claude Code 是 Anthropic 的命令行 AI 编程助手，每个终端窗口运行一个独立会话；该功能相当于让同时运行的多个 AI 代理自行协调、互相传递任务上下文，类似于为 AI 工作流增加一个内部通知系统。

  • 从 Claude Code v2.1.224 开始，同机会话消息开箱即用，Claude 可通过 ListAgents 发现目标，用 SendMessage 发送信息。
  • 消息受三层限制：不能代表用户批准权限、不能修改配置、文本中的命令不执行，避免会话越权。
  • 支持同机和跨机通信，但跨机仅能回复已收到的消息，无法主动发起跨机会话。
  • 设置 crossSessionInbound 可控制接收策略：接受、仅通知、拒绝，非交互式会话可通过 --settings 调整。

💬 讨论 评论区普遍认为该功能解决了多会话上下文重复传递的痛点，许多开发者此前已用 tmux、内存树或 IRC 服务器等自制类似系统，认可其实际效用。
