## 4. [LeMario: Training a JEPA World Model on Super Mario Bros](https://www.benjamin-bai.com/projects/lemario)
*LeMario：在超级马里奥兄弟上训练 JEPA 世界模型*
▲ 64 分 · kevinjosethomas · [8 评论](https://news.ycombinator.com/item?id=48913763)

📝 **概要**：作者用 JEPA 架构在 32 个马里奥关卡上训练世界模型，五步预测误差比基线低 45.5%。但用 CEM 在潜在空间做无奖励规划时，马里奥仅能短距离移动；因为编码器学会了所有可预测特征（HUD、敌人、相机滚动），导致视觉相似的远方场景在潜在空间中距离很近，将进展度量完全混淆。

🧭 **联系你的知识背景**：JEPA 学习压缩像素表示，以预测未来帧，相当于自监督的表示学习；本文发现，这种表示对预测是好用的，但对衡量任务进展而言是失效的距离度量，好比训练一个预测模型却选了与最终决策不匹配的优化目标。

**🔑 要点**
- 五步递归预测误差比“不做变化”基线低 **45.5%**，证明模型确实学会了基于动作的短期动力学。
- CEM 用潜在距离规划时，马里奥最多移动几像素，且因 **垂直位置表示极弱** 而无法跳过任何障碍。
- 训练线性探针从潜在表示解码水平位置后，用探针得分引导规划，马里奥成功到达 **x=176**（目标 x=177）。
- 根本问题是编码器无差别地保留所有可预测特征，导致 **潜在距离不可靠**：视觉相似但位置不同的场景在表示中高度混叠。

💬 **讨论**：评论认为 JEPA 学会的语义表示没有按控制重要性加权，规划器应直接最大化探针预测的位置，或对潜在空间结构进行重构，这也暗示纯自监督世界模型难以直接用于长时间规划。

🏷️ `JEPA` · `世界模型` · `表征学习` · `模型预测控制`

## 10. [Show HN: Juggler – an open-source GUI coding agent, by the creator of JUCE](https://github.com/juggler-ai/juggler)
*Show HN: Juggler —— 由 JUCE 作者打造的开源 GUI 编程智能体*
▲ 193 分 · julesrms · [81 评论](https://news.ycombinator.com/item?id=48883305)

📝 **概要**：Juggler 是 JUCE 作者打造的 GUI AI 编程智能体，将对话变成可分支、可回溯的树形文档，用 Miller 列视图替代线性滚动日志，并通过 JavaScript 插件化架构实现高度可定制，支持多客户端实时协同，已开源为 AGPLv3。

🧭 **联系你的知识背景**：你可以把 Juggler 理解为用 macOS Finder 列视图来管理 AI 编程对话的「可操作工作台」，底层的 Yjs CRDT 类似 Google Docs 那种多人实时同步技术，让桌面、浏览器、手机可以同时查看同一个会话。

**🔑 要点**
- 会话采用**树形分支结构**，可以创建子线程、回溯、比对不同尝试，彻底告别 doom-scroll 日志。
- 基于 **Yjs CRDT** 实现多客户端 P2P 同步，桌面、浏览器、手机可同时接入同一编程会话并保持同步。
- 几乎所有对象均为** JavaScript 插件**：上下文项、策略、斜杠命令及其 UI 都可检查、复刻或替换。
- 项目采用 **AGPLv3** 许可，扩展 SDK 和内置扩展为 Apache-2.0，无需注册、无遥测，开箱即用。

💬 **讨论**：社区普遍欣赏 GUI 和树形对话的创新，但也有开发者希望加入 ACP（智能体通信协议）支持以复用现有插件，以及借鉴 Slack 风格侧线程增强协作。
