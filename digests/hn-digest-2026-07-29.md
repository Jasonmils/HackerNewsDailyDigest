## 4. [Truth is not a direction: a Tarski attack on LLM probes](https://abeljansma.nl/2026/07/10/truth-is-not-a-direction.html)

▲ 33 分 · abelaer · [8 评论](https://news.ycombinator.com/item?id=49069033)

📝 **概要**：作者用对角线论证证明，任何在 LLM 嵌入空间上定义的可描述自身的真值探针都会遇到说谎者悖论，永远无法成为通用真值预言机；实验中 Qwen3.5-4B 探针准确率 94% 但无法处理自指语句。

🧭 **联系你的知识背景**：本文借哥德尔不完备定理和塔斯基真值不可定义性的对角线构造，攻击了 LLM 中的“线性表征假说”——即自然概念对应嵌入空间方向的看法——说明任何能描述自身输出的语言都无法拥有完备的真值谓词。

**🔑 要点**
- **任何可定义的语言模型探针**都无法在足够丰富的语言中完全捕捉真值，因为自指语句会引发对角线悖论。

- 这类探针虽不是真值预言机，**仍可实用**，类似数学未被不可判定性阻碍，可帮助理解模型行为和预警错位。

🧭 **联系你的知识背景**：你熟悉的 RoPE 是 Transformer 提供词序信息的位置编码方法，Kimi K3 却全部舍弃，改用 NoPE（无位置嵌入），靠注意力自身隐式捕捉位置。

**🔑 要点**
- **2.8 万亿参数**，由去年 48B 的 Kimi Linear 架构直接规模化而来，是至今最大开放权重模型。
- **完全移除 RoPE**，全模型使用 NoPE，这在首个前沿级模型中实现，打破了位置编码的必要性假设。
- 新增 **LatentMoE** 对大型线性层做降维压缩，类似多头潜在注意力的思路，提升推理效率。
- 注意力残差改善残差路径，付出 **4% 额外训练成本和 2% 推理成本**，换来验证损失与下游性能的一致提升。

💬 **讨论**：评论区分成两派：一派认可 Kimi 引入的创新而非仅靠蒸馏，另一派质疑线性注意力的信息损失与架构可复现性。

📝 **概要**：MCP 协议核心从有状态双向流转变为无状态请求/响应，消除会话管理负担，提升负载均衡和弹性伸缩能力。SDK 月下载近 5 亿，TypeScript 和 Python 总下载均超 10 亿，反映代理工作流的广泛采用。

🧭 **联系你的知识背景**：有状态协议要求服务器记住每个客户端的上一次交互（类似保持电话不挂断），无状态则每次请求独立，服务器不保留上下文，更易水平扩展和容错。

**🔑 要点**
- 协议**移除初始化握手和会话 ID**，每个请求自描述，可直接落在任意服务器实例，无需共享存储。
- 新增**多轮往返请求（MRTR）**机制，支持工具执行中向用户请求输入，不再依赖常开双向流。
- 列表响应携带**缓存提示和确定性顺序**，客户端可缓存工具目录，降低重复请求。
- 授权层引入 **RFC 9207 验证**和**客户端元数据文档（CIMD）**，弃用动态客户端注册，关闭授权服务器混用漏洞。

💬 **讨论**：评论普遍认可无状态化，多人提及状态管理曾是网关和基础设施的主要痛点，期待简化 MCP 服务器的部署与维护。
