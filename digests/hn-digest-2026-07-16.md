## 8. [Designing APIs for Agents](https://www.freestyle.sh/blog/opinion/designing-apis-for-agents)
*为 AI Agent 设计 API*
▲ 59 分 · benswerd · [31 评论](https://news.ycombinator.com/item?id=48894874)

📝 **概要**：作者提出面向AI Agent的API设计应放弃人类便利性：消除默认值、拒绝隐式纠错、使用极精确的字段名，让API只提供“事实”（如付款、发消息），而非可本地复现的工具函数。其产品Freestyle据此移除了复杂SDK抽象，以纯指南代替。

🧭 **联系你的知识背景**：文中Agent指LLM驱动的编码工具（如Claude Code），它们能一次性阅读完整文档并生成数千行代码，因此设计逻辑与为人设计API截然不同。

**🔑 要点**
- **默认值有害**：Agent应显式填入所有字段，隐式默认会增加理解歧义和排查成本。
- **拒绝隐式纠错**：API不应自动修正大小写或接受多义输入，让Agent在错误提示中澄清误解，而非产生不一致代码。
- **字段名须精确唯一**：用`displayName`、`slug`等代替`name`，消除Agent对通用字段的五种不同解读和幻觉。
- **API只需提供事实**：核心是完成计费、发消息等不可替代的副作用，任何工具函数均可被AI本地重写，无需封进SDK。

💬 **讨论**：评论者补充了为Agent提供反馈工具、文本优先接口、批量操作等建议，共识是显式与可调试比简洁更重要。

🏷️ `AI Agent 接口设计` · `API 设计原则` · `开发者工具`

📝 **概要**：deja-vu 将编程代理的历史对话转化为本地可搜索的内存层，搜索 7-9 毫秒，支持跨代理回忆、自动上下文注入、凭据脱敏和 SSH 同步；零依赖，无模型下载，数据不出机器。

🧭 **联系你的知识背景**：SSH 是一种加密网络协议，用于在两台机器间安全传输文件，deja 利用它实现无需中心服务的多机内存同步，类似去中心化的文件共享。

**🔑 要点**
- 将多个编程代理的历史对话本地化索引，**7-9 毫秒**内搜索数 GB 记录，支持数月前的回溯搜索。
- 提供 MCP 召回工具和 SessionStart 钩子，**自动注入 2KB 相关记忆**，避免重复调试。
- 索引时**自动脱敏 API 密钥和私密数据**，分享和同步导出时再次清洗，安全共享会话摘要。
- 通过 JSONL 批处理实现 **SSH 同步**，增量式、幂等、仅追加，便于跨机器传递内存层。

💬 **讨论**：评论普遍认同本地化、轻量级内存工具的价值，有人自建类似系统；但对于是否需要增加语义搜索存在分歧，部分用户坚持确定性文本匹配的简单可靠。
