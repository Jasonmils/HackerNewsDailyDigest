“Next-token predictor” is the wrong mental model for LLMs

「Next-token predictor」是 LLM 的错误心智模型

▲ 94 分 · garrinm · 216 评论

文章认为后训练（尤其 RLVR）让 LLM 从自身探索的新序列中学习，而不只是预测已有语料里的下一个 token。“下一 token 预测器”只描述输出机制形状，忽视模型编码的助手行为与探索所得知识，容易低估模型能力来源。

🧭 联系你的知识背景 你熟悉自回归训练与奖励优化；本文的重点不是推理时的逐 token 生成，而是后训练阶段参数更新信号从“模仿已有 token”切换到“奖励驱动的探索序列”，这决定了术语是否合适。

  • RLVR（带可验证奖励的强化学习）让模型从自身探索生成的新序列中学习，而非仅预测训练数据里已有的下一个 token。
  • 预训练循环提高语料中真实出现的下一个 token 概率；RLVR 循环根据任务结果奖励提高被探索 token 的概率。
  • 国际象棋类比中，穷举探索后选择胜率最高着法的引擎不应叫“下一步棋预测器”，因为它不是模仿已有棋谱。
  • 文章认为“next-token predictor”只描述逐 token 发射机制的形状，忽略了后训练模型编码的助手行为和探索所得知识。

💬 讨论 HN 评论多数认为后训练并不会使“next-token predictor”失效，训练目标仍是学好预测下一个 token；分歧在于这个术语是否隐含只能模仿已有数据的局限。

To be honest, I believe I get the point the article is trying to make, and to an extent I agree, but I also think the point is not really made very well.

The core of the argument as I understood it is that LLMs aren't just using existing data is training but also new ones.
