Mistral 发布机器人导航模型 Robostral Navigate，8B 参数，仅用单 RGB 相机在 R2R-CE 未见环境中达到 76.6% 成功率，超过多传感器方法 4.5 个百分点。模型完全基于模拟数据训练，并通过在线强化学习进一步提升，展示出低成本视觉导航的实用化潜力。

🧭 联系你的知识背景 文章中的“prefix-caching”是一种训练优化方法：利用树状注意力掩码将整个导航轨迹的所有时间步压缩在单个序列中，避免重复计算公共前缀，从而将训练 token 数减少 22 倍。

  • Robostral Navigate 8B 模型仅凭单 RGB 相机，在 R2R-CE 未见环境中取得 76.6% 成功率，超越多传感器方案 4.5 个百分点。
  • 训练完全基于模拟数据（约 400,000 条轨迹），通过 prefix-caching 将训练 token 数减少 22 倍，显著缩短训练周期。
  • 采用 CISPO 在线强化学习进行后训练，成功率提升 3.2%，模型能自主从失败中恢复并产生探索行为。
  • 导航采用指向 (pointing) 方式，推理出相机画面中的目标坐标，天然适应不同相机内参和多种机器人形态（轮式、腿式、飞行）。

Benchmarking coding agents on Databricks' multi-million line codebase

在 Databricks 数百万行代码库上基准测试编码代理

▲ 21 分 · tanelpoder · 5 评论

Databricks 在自身数百万行多语言代码库上构建内部基准，发现开源模型 GLM 5.2 的任务完成质量与昂贵闭源模型 Opus 4.8 相当（$1.28/任务 vs $1.94），且 token 价格不能反映总任务成本；不同调用工具（harness）可导致成本差 2 倍以上，推动了混合使用不同智力层级模型的策略。

🧭 联系你的知识背景 文章中的 “harness”（调用代理的外壳）会在每次交互时给模型喂入不同量的上下文，这与模型推理时处理 token 数量的效率类似，影响总成本但不一定影响答案质量。

  • GLM 5.2 开源模型在编码代理基准中进入顶级梯队，质量与闭源 Opus 4.8 统计无差，但每任务成本仅约三分之二。
  • 每 token 价格不能反映实际任务成本：Sonnet 5 每 token 便宜 1.7 倍，但因消耗 1.9 倍更多 token，总任务成本反而高于 Opus 4.8。
  • 调用工具对成本影响巨大：同一模型在不同 harness 下成本可差 2 倍以上；Pi harness 通过减少上下文，使任务更快完成且成本更低。
  • 自建内部基准更可靠：避免公开基准数据泄露，且贴合自身多语言代码库的实际任务分布，能直接指导模型和工具的选型决策。

💬 讨论 HN 评论普遍认同低成本模型会消耗更多回合完成任务的观察，并强调每个团队都应构建自己的基准以避免公共基准的失真。

  • Frugon 是 MIT 许可的本地 CLI 工具，读取 OpenAI 格式 JSONL 日志，估算切换到更便宜模型可节省的费用。
