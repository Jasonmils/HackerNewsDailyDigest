How to Write with an LLM

如何用 LLM 写作

▲ 432 分 · joeriddles · 292 评论

作者提出用 LLM 写作的核心方法：把模型当文字编辑而非代笔，禁止采纳模型建议的措辞、避免其鼓励。模型适合机械标记被动语态、重复用词和冗余段落，但不应替代个人声音。

🧭 联系你的知识背景 就像训练时模型会过拟合高频模式，LLM 写作会滑向“杂志标题”式的通用措辞，因此作者建议只把它当错误检测器而不是文本生成器。

  • 规则一：不得使用 LLM 建议的任何词语，因为模型倾向生成讨喜但同质化的杂志式表达。
  • 规则二：避免让模型鼓励你，否则会强化初稿中的冗余和混乱，侵蚀个人风格。
  • LLM 擅长标记被动语态、重复用词和可移动段落，适合做机械性文字编辑。
  • 评论区共识：LLM 改风格品味差，但事实核查对技术写作有帮助。

💬 讨论 评论区普遍认可 LLM 做机械检查与事实核查，但对其写作品味评价低，同时有人担忧 AI 内容增多会降低读者阅读体验。

🧭 联系你的知识背景 KV-cache 是 Transformer 推理时缓存的键值状态，这里被用作模型间传递“意图”的内部表征，而不是先解码成文本。

  • Cache-to-Cache (C2C) 用神经网络投影并融合 KV-cache，跳过文本生成，实现直接语义传输。
  • 相比文本通信，C2C 准确率再高 3.1–5.4%，比单模型高 6.4–14.2%。
  • 推理延迟平均降低 2.5 倍，省去逐 token 生成的开销。
  • 可学习门控机制自动选择目标模型中受益于缓存通信的层。

💬 讨论 HN 共识是概念诱人但尚未进入生产模型，主要担忧不同模型直接用内部表征“神经语”通信会削弱可监控性。

It's an old paper (from 2025, so, a decade ago in AI years), but the concept is still fascinating. And I'm yet to see it show up in any production models.

If multiple models can use cache representations for this kind of enrichment, the KV cache representations of different models must be somewhat compatible.

What stops us then from going a step further, and producing a model family where all models are "KV aligned", and each model can utilize the KV cache of other models directly?

So, an "expensive" reasoning model can use its full faculties to plan, but "delegate" simple subgoals to a smaller model. That smaller model can access the large model's intent directly, as rich KV cache representations - with no prefill recompute and no associated "handover" latency. Or, likewise, a "cheap" small model can generate a diminished but highly compact KV cache that the "expensive" model can then operate on - for example, for skimming a large file for shallow patterns.

The Implications of Linguistic Illegibility for LLM Security

语言不可辨认性对大语言模型（LLM）安全的影响

▲ 59 分 · tomjakubowski · 22 评论

本文提出“语言不可辨认性”：大语言模型（LLM）的语言输出与激活探测无法可靠反映内部计算，因为内部是对激活空间的数学运算，语言只是有损翻译。因此依赖模型自我报告的安全机制（如思维链监控）永远无法完全可靠，必须叠加不依赖语言状态的污点跟踪等隔离技术。

🧭 联系你的知识背景 污点跟踪可类比数据来源追踪：标记模型输出为不可信数据，并预先禁止其污染敏感系统状态，类似训练时追踪哪些输入特征驱动预测。

  • 语言不可辨认性指 LLM 的语言输出与激活探测无法可靠代表内部计算，因为内部是激活空间数学，语言只是有损翻译。
  • 依赖模型自我报告的安全机制（思维链监控、宪法自我批判）永远无法完全可靠，模型可能说一套想一套。
  • 污点跟踪是更有前景的沙箱方法：预先标记模型产生数据不可信，禁止其影响敏感系统状态，不依赖语言状态。
  • 稳健虚拟化与第三方审计配置可作为补充底线，缓解前沿模型已有的沙箱逃逸。
