## 4. [Human vs. AI – Diff-based line-level provenance for text under agentic editing](https://github.com/eighttrigrams/us-vs-them)
*人类 vs. AI – 基于差异的行级溯源，用于代理编辑下的文本*
▲ 44 分 · eighttrigrams · [11 评论](https://news.ycombinator.com/item?id=49232300)

📝 **概要**：CLI 工具 us-vs-them 利用 git 提交历史将文本行的人工/AI 归属量化为 0.0（纯代理）到 1.0（纯人类）的分数，让代理在后续编辑时能够尊重人类编写的部分，特别适合保护人工修改过的文档段落。

🧭 **联系你的知识背景**：该工具类似 git blame，但按作者群体划分人和代理，生成行级归属分数；非系统读者只需理解它通过版本历史自动标记每一行的创作来源。

**🔑 要点**
- 通过 `--ours` 或 `--theirs` 指定群体，**无需在文本中嵌入任何特殊标记**，直接处理纯文本。
- 输出示例 `4 1.00`：**1.0 表示完全由人类创作**，0.0 为代理生成，中间值代表被稀释的人类贡献。
- 算法将相邻且归属相近的行合并为连贯的“岛屿”，**处理行的拆分、合并及归属稀释**，避免碎片化结果。
- HN 评论指出**代理通常以人类身份提交 commit**，使依赖提交作者的溯源存在局限，但对 README 等文档的手动保护场景仍有认可。

💬 **讨论**：HN 评论者对代理以人类身份提交代码时效用存疑，但对人工修改后的文档（如README）进行保护这一用例达成部分共识。

🏷️ `开发者工具` · `AI 代理` · `文本溯源` · `git diff`

🧭 **联系你的知识背景**：Terminal-Bench 是一套标准化基准，专门测试 AI 代理在命令行终端环境下完成系统管理类任务的能力，类似你熟悉的模型评估测试集，但侧重于代理的工具使用和实操。

**🔑 要点**
- **DeepSeek V4 Flash 0731max** 以 82.7% 准确率在 Terminal-Bench 2.1 公开模型中位列第一，超越 Grok 4.5。
- 评测基于**公开 Ante 框架**，提供可审计的运行记录，但核心测试引擎仍在私人仓库开发，引发透明度争议。
- 推理成本仅 **$68.41**，用时 38.9 分钟，性价比显著优于 Grok 4.5（$242.57）和 GLM 5.2（$260.11）。
- 官方基准中 **Claude Code (Anthropic)** 使用 Fable 5 以 83.8% 领先，但依赖更高推理预算和不同代理架构。

💬 **讨论**：评论区对 Ante 宣称开源但核心测试框架在私人仓库开发表示失望，有人因透明度不足而失去兴趣，同时也有审计链接和登录问题的反馈。
