## 3. [Apple's new SpeechAnalyzer API, benchmarked against Whisper and its predecessor](https://get-inscribe.com/blog/apple-speech-api-benchmark.html)
*苹果新 SpeechAnalyzer API 与 Whisper 及前代 API 的基准对比测试*
▲ 481 分 · get-inscribe · [191 评论](https://news.ycombinator.com/item?id=48894752)

📝 **概要**：苹果 iOS/macOS 26 内置的 SpeechAnalyzer 在 LibriSpeech 上的词错误率（WER）低至 2.12%（干净语音）和 4.56%（噪声语音），显著优于自家的旧版 API（9.02%）和 Whisper Small（3.74%），且速度快约 3 倍，成为当前 Apple 设备上英语语音识别的最佳选择。

🧭 **联系你的知识背景**：WER（词错误率）类似于分类任务中的错误率，但衡量的是转录文本中替换、删除或插入的词占参考文本总词数的百分比，数字越低越好。

**🔑 要点**
- **SpeechAnalyzer 词错误率仅为 2.12%**，比 Whisper Small 低 1.62 个百分点，同时推理速度快 3 倍，无精度妥协。
- **旧版 API 的 WER 高达 9.02%**，新 API 将其改善了 3.5-4 倍，迁移几乎只有收益。
- **Whisper 模型仍覆盖 100+ 语言**，而 SpeechAnalyzer 仅支持约 30 种语言，因此多语言场景仍依赖 Whisper。
- **开发团队 Inscribe 已将其默认引擎切换为新 API**，并公开了原始转录数据以供独立验证，增加基准可信度。

💬 **讨论**：评论认为应对比更强的模型如 Nemotron、Voxtral，但普遍认同苹果新 API 会挤压仅封装 Whisper 的付费应用，并且最终用户将无需第三方工具。

## 9. [Show HN: Jacquard, a programming language for AI-written, human-reviewed code](https://github.com/jbwinters/jacquard-lang)

▲ 60 分 · jbwinters · [29 评论](https://news.ycombinator.com/item?id=48894630)

📝 **概要**：Jacquard 让函数副作用（网络、文件系统等）在签名中显式可见，运行时需显式授权，并通过内容寻址哈希使重命名和格式改动无需重编译。已发布可安装的 0.1 研究原型，包含记录回放与概率测试框架 Warp。

🧭 **联系你的知识背景**：效应系统可类比模型训练的显式配置：每个函数必须声明它会执行哪些外部操作，使 AI 生成的代码更容易被人类审查，而内容寻址哈希类似模型权重的不可变标识。

**🔑 要点**
- 函数签名显式列出**效应（如 net、fs）**，运行时拒绝未授权的世界交互，需要 --allow 显式开放权限。
- 采用**内容寻址的规范身份哈希**，注释、格式化、重命名不影响下游代码，纯测试仅在规范代码或依赖变更时重新运行。
- 同一份代码可针对**真实网络、录制的流量、脚本化的假世界或概率模型**运行，通过替换 handler 实现零改动换世界。
- 内置**测试框架 Warp**，融合回放、结果缓存、handler 替换和精确概率枚举，支持 AI 修补程序后计算候选补丁的后验概率。
