📝 **概要**：ds4 是 Redis 作者 antirez 开源的 C 语言本地推理引擎，采用非对称 2-bit 量化压缩 MoE 专家、保持关键共享路径高精度，使 DeepSeek V4/V4.1、GLM 5.x、Qwen3.8 等模型可在 128GB 内存 Mac 上运行；在 M5 Max 128GB 32K 上下文下实现 34.4 token/s 生成、557 token/s prefill。

**🔑 要点**
- **ds4** 是 Redis 作者 antirez 开源的本地 LLM 推理引擎，MIT 许可，支持 DeepSeek V4/V4.1、GLM 5.x、Qwen3.8。
- 采用**非对称 2-bit 量化**压缩 MoE 路由专家、保持共享路径精确，使模型适配 128GB 内存设备。
- **M5 Max 128GB 32K 上下文**下生成 34.4 token/s、prefill 557 token/s；DGX Spark 64K 生成 13.8 token/s。
- 提供 **CLI、HTTP API 和本机 agent**，API 兼容 OpenAI/Anthropic 风格，便于本地编码代理接入。

💬 **讨论**：评论普遍认可 ds4 在 M5 Max 上的实际运行速度和长上下文能力，但关注点分散在跨语言绑定、工具调用表现以及它与其他本地推理工具相比的通用性/专业性权衡。
